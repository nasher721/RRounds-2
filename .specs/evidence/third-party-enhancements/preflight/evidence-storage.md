# Preflight contract: immutable evidence storage

Status: `BLOCKED-PREFLIGHT`; no immutable store has been selected or approved.

Local `.specs/evidence/` is staging only. Before execution select an append-only,
access-controlled store with object/version retention, final URI/key naming,
SHA-256 hashes, access logging, retention period, and named deletion authority.
Raw results, manifests, metadata receipts, content-bearing recovery artifacts,
signatures, and corrections must be versioned there. A local path, telemetry
event, or checksum-only receipt is not final evidence. Store/custodian/approval:
`UNASSIGNED`.
